# Relay workspace planning with ChatGPT — 6 November 2026

Relay defaults to on-device Gemma. The setup assistant and Settings → Model offer an explicit, session-only switch to ChatGPT via a verified installed Codex CLI. The CLI checks for and reuses a local ChatGPT sign-in. Relay has no account, stores no API key, and does not switch to hosted planning automatically.

Sentient OS 2.7.6 also separates hosted reasoning from local Mac control. Relay uses its existing verified tool dispatcher, action reviews and Stop control. The CLI proposes one structured action at a time; Relay validates the proposed name and arguments and owns execution. The hosted provider does not receive prior chat, memories, grants, calendar, indexed sources, files, screenshots or background tasks. App lists and visible app or web excerpts require a separate review of the exact bounded text before Relay sends it.

The CLI qualification is specific to the signed arm64 build tested here. Unknown builds are unavailable until qualified. The fixture tested the request sent by the pinned CLI and model against a local stand-in, with no credentials or personal context. It verified that neither top-level nor nested native tools were advertised and that injected shell and user-input calls were rejected. The CLI process also runs with child-process creation and user file writes blocked. Interactive control still depends on the app’s macOS Accessibility grant and the controls the target app exposes.

Live acceptance used the installed arm64 Codex CLI `0.166.0-alpha.5.1` and GPT-6.1 Terra. An opt-in client smoke test returned the exact requested synthetic answer using the existing ChatGPT login. In a separately signed QA app with no local model or production conversation, “Open Calculator” returned “Calculator is open,” and Relay recorded the independently verified `com.apple.calculator` process. A separate synthetic Safari navigation reached exact destination review; declining it recorded that no action ran. The regular release passed deep code-signature verification and reopened with the local provider selected. Its existing Accessibility grant was absent and was not changed.

The full Swift run registered 535 tests with the offline login check enabled: 518 ran successfully and 17 opt-in cases were skipped. The hosted client smoke ran separately. Ten Python fixture/release checks and 149 repository scenario checks passed. This covers the workspace provider addition; background account sync, cross-device cloud sharing, and autonomous overnight wake remain outside the verified parity scope.
