## Current implementation batch

- Generic desktop observations and control references now bind the intended foreground app process, including duplicate Chrome profiles, launch identity and canonical application path. A stale reference cannot silently rebind to another profile. Browser text-entry readback polls the same exact field after one write; it never retries a write while waiting for Chromium's accessibility cache.
- Reviewed native checkbox and disclosure changes use a single press and exact state readback, with verified no-op receipts. Radio choices bind the full named peer group; table rows bind the complete supported table snapshot and use only direct row selection. They do not open, press or activate a row. Ambiguous, disabled, mixed, interactive-row, consequential and permission-changing contexts refuse. These are bounded adapters, not unrestricted desktop control.
- Browser/PDF summaries have up to four independent memory-only readers and one serialized local inference queue. Invocation pins the original browser app launch, window, selected tab and loaded document before deferred capture. PDF reads and retained authorization bind the original canonical path. Captures are limited to 8,000 UTF-8 bytes; PDFs need a text layer, at most 10 MB/20 pages, and bounded extraction. Long text uses opening/middle/ending excerpts with visible gaps. Editable browser values are excluded. Source and result stay out of chat/state, and closing, Stop, sleep or revoked PDF access clears them.
- Optional configurable Summarize/Proofread global shortcuts have reserved-command and collision checks. Relay retains ⌘, for Settings and ⌘. for Stop. Source capture begins only on invocation. Cold browsers can refuse until a document is exposed through Accessibility.
- Explicitly linked people/projects can generate a reviewed cross-source brief from two to eight selected linked sources. Local inference selects existing excerpt IDs; deterministic rendering quotes the original text with version-bound source references. It does not infer identity or synthesize new facts. Saving creates an independent editable historical snapshot rather than changing source notes.
- Each connected display has a passive Sidekick entry handle, sharing one task, draft and review. Native press/hold starts local dictation; release stops microphone input immediately and waits briefly for the final transcript. The transcript is editable. Release-to-send is separately opt-in and requires an unchanged final local transcript, the same known originating app and an empty unchanged prompt. Edits, cancellation, Stop, sleep, ownership changes and hosted workspace mode do not automatically submit.
- The full default local task loop passed an inert native workflow with Gemma 4 E2B CPU: observe, exact Unicode text write, automatic readback of the original window, fresh Apply reference, one complete-form review, one Apply and an independent result observation. It used production AssistantStore/MacTools without an executor override and took 138.127 seconds. This fixture proof does not qualify every app, model or the packaged Relay permission identity.
- Explicitly selected SiYuan workspaces now include open-notebook document trees, breadcrumbs and bounded AttributeView rows with dependency hashes. Closed notebooks, encrypted content and guide documents are excluded. Indexing, persisted restore, database-only drift and dependent cache/brief withdrawal passed synthetic fixtures. Double Tap can use relevant authorized knowledge excerpts; its model-only payload omits local paths while retaining exact local revision receipts for insertion checks.
- Default tasks no longer stop at four active minutes, 30 minutes of lifetime or 20 planning turns. Individual call deadlines and Stop remain. Recovery is counted per unresolved operation and observed target; verified unrelated work cannot clear a failed action. Completed-prefix context and durable task checkpoints remain open work.

- Reviewed plain-text Apple Mail drafts and sends using the existing Mail account. Each write requires an exact displayed approval. Sending rechecks sender, To/Cc/Bcc, subject, body, attachment state and approval expiry. Automatic Cc/Bcc settings refuse. Uncertain submission cannot be automatically replayed. Mail acceptance is distinct from recipient delivery. These paths are qualified with synthetic transports, not a live mailbox.
- Opt-in refresh of the original selected Notes and Mail items while Relay runs. The scope remains at most eight selected items per source, excludes locked items, and expires when the original source process changes. Session content and the refresh preference are not persisted.
- Exact dropdown values are forwarded to the desktop helper. The native adapter supports named, non-consequential AppKit `AXPopUpButton` controls with at most 64 inspected menu items and one exact, enabled choice. Independent live fixture readback covers Unicode, stale reviews and absent/duplicate/disabled choices. This does not qualify arbitrary dropdowns or consequential form submission.
- Selected-text summaries and proofreading use tool-free local inference in a temporary result window. Native proofreading shows both versions, binds an exact selection and full field, dispatches at most one replacement, and checks the complete resulting field. Browser fields, changed targets and unsupported formatting use copy-only output. Closing or Stop clears the session; selected text and results do not enter chat history or saved state. Live synthetic editors qualify the replacement adapter. A separate real Gemma 4 E2B CPU check passed exact spelling correction while preserving a blank paragraph, accented text and emoji (4.809 seconds), without dispatching an edit. An explicit no-Markdown/no-fences prompt fixed the observed response-wrapping failure; the complete, single-key JSON parser remains strict. This one example does not establish general proofreading quality.
- Browser selection uses the intended foreground process when several profiles are running. Cold startup waits for a native window before address entry. Unsupported targeting refuses a fallback that could navigate another profile.
- Agent execution steps retain bounded, whole verified receipts, allowing later steps to use opaque draft/review identifiers without inventing them. Receipt context is reset for a new task.
- System settings group startup, manual public release checks and diagnostics. The update checker uses no Relay account and opens a validated release page. It does not install an update automatically.

These establish reference behavior, not permission for Relay to adopt the same hosted services. Local parity requires equivalent outcomes through an explicitly supported local path, with its own capability and quality qualification.
