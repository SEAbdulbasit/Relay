# Relay chat declutter implementation — 20 November 2026

This pass responds to the actual failed-calendar screenshot and the current Reference source/interface comparison. It changes the working chat, not another marketing hero or palette. Root owns native app observation, calendar integration, the shared atmosphere/material helper, final compilation, and qualification.

## Changed in MainView.swift

- Ordinary assistant responses use plain Markdown without a repeated Relay avatar/name header. Factual multi-agent role badges and System labels remain where relevant.
- Removed permanent Copy/Save/More strips and the three circular edit/reply/copy buttons under every user message. A reserved narrow hover/focus menu holds the same actions. Named accessibility Copy/Reply/Edit/Save actions and the existing context menu remain available independently of visual hover.
- Saving still has actual saved/failure feedback. Open note and Export appear only after a response was saved, and errors/retry remain visible. Existing stable capture IDs and source revalidation are unchanged.
- History rows no longer advertise a Trash icon beside every title. A quiet selected/hover/focus menu offers Rename, Pin, Copy, Export and Move to Trash, with existing context-menu and named accessibility actions retained.
- The composer has one `+` menu for attachments/tools, a short model picker, microphone, and Send/Stop. Removed the permanent Work in app and Actions labels and the full provider title. The picker retains the complete model name in its accessibility label/help.
- Attach app window explicitly clears any prior image-ready auto-execution callback. Attachment is context selection, not automatic task submission. Image file/paste choices also clear that callback.
- Calendar setup is discoverable in `+ → Calendar setup…`, routing the existing Sources settings. Rendering or choosing this navigation entry does not load Calendar, request permission, or select a calendar.
- Empty `showImageInspection` mode no longer produces a large five-action Visual Target Context panel. Actual attachment is a small thumbnail/name/Inspect/remove row; active picker/load and meaningful feedback remain compact and dismissible. Idle and canceled selection produce no permanent placeholder.
- Header keeps sidebar/Relay, conditional Stop, icon search, Brief/Knowledge navigation, and one gear Workspace menu. Settings, appearance, setup and existing conversation copy/export/find/clear actions are in that menu. Navigation labels become icons below 980 points with accessibility labels intact.
- Composer is bounded to 780 points, uses a 15-point 1–5-line input, 36-point mic/Send targets, root's `relayWorkspaceSurface` material, and root's `RelayWorkspaceBackdrop`. The header stays transparent so the shared crown atmosphere remains visible. Chat turns use tighter spacing and reserved action gutters without hover-driven relayout.

## Scope and qualification

No model/tool approval or task-recovery authority was changed. No calendar event was created or source permission enabled by this lane. Saved-result persistence and Trash data models remain intact. The existing large dirty checkout was preserved.

Swift parser and scoped whitespace checks passed. No build or runtime test was launched in this lane, so parser success is not a claim of successful type checking or VoiceOver qualification.
