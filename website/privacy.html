Core Principles

The Four Pillars of Relay Sovereignty

How Relay handles local inference, file access, notes, and model downloads.

1. Local Inference by Default

Once the Gemma model is installed, local inference works without internet access. Downloads, browser tasks, optional ChatGPT, and services you select can use the network.

2. Scoped Permission Boundaries

Relay limits file access to files and folders you select. Inspecting and controlling other apps also depends on macOS permissions.

3. Open Markdown Storage

Relay stores conversation history and the activity log on your Mac. You can export selected notes as Markdown.

4. Cryptographically Verified Weights

Relay verifies the pinned Gemma download against its SHA-256 checksum before use.

Don't Take Our Word For It

Audit Local Inference on Your Mac

For an air-gapped inference check, install the local model first, disconnect from the network, then ask Relay a question with Gemma selected.

1. Inspect Relay’s Network Sockets with lsof

While Relay runs a local task, inspect Internet sockets open in the Relay process. Check browser and CLI processes separately for their own connections.

# Inspect Internet sockets opened by the Relay process
$ lsof -a -c Relay -i
This is a point-in-time process check.

2. Confirm Gemma Works Offline

Select the installed Gemma model, disconnect your Mac, and ask a question that needs no website or remote service.

# Example prompt in Relay
What is 7 × 8?
The local model can answer without a network connection.

3. Try the ChatGPT Data Review

In ChatGPT mode, request an inspection of an app window. Relay displays the excerpt and gives you the choice to share it or keep it on your Mac.
