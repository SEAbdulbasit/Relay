Frequently Asked Questions

Everything you need to know.

Clear answers about offline execution, model safety, system access, and privacy.

Does Relay send any data to external servers or cloud APIs?
Gemma inference runs on your Mac by default. If you choose ChatGPT via Codex CLI in Settings → Model, your workspace request and action status go to OpenAI. Relay asks before sharing an app list or visible app or webpage text. Downloads, browser tasks, and services you choose can also use the network.
How does multi-agent coordination work without cloud servers?
Relay implements a local turn-based Blackboard Architecture. Instead of querying a cloud LLM, Relay passes a shared in-memory blackboard across four on-device roles: the Planner deconstructs the request into goals; the Navigator performs read-only system reconnaissance; the Executor invokes scoped tools; and the Critic verifies that postconditions match user expectations.
What permissions does Relay require on macOS?
Relay asks for macOS Accessibility permissions so the Navigator agent can inspect active window elements and UI controls. Relay limits file operations to files and folders you select and to the access you grant.
Which models are bundled or supported?
Relay is optimized for Google Gemma 4 E2B packaged in LiteRT-LM format (`.litertlm`). Relay verifies the pinned download with SHA-256. You can also select a compatible `.litertlm` model from your own drive.
Can I cancel or stop an agent task while it is executing?
Click Stop to cancel planning and block new tool dispatch. An action already underway may finish, and Relay reports its outcome when it can verify it.
